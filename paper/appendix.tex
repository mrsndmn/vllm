\path{scripts/paper/token_lengths.py} generates the baseline workload tables.
It reads completed \texttt{done.json} outputs and checks saved configurations against
the source registry, complete sample counts, unique sample identifiers, and
stored input-token counts when available. Profiling rows that re-score a fixed
reference response are excluded. Missing runs are recorded as pending in the
provenance file rather than treated as zeros. The generated provenance records
sample, configuration, marker, and tokenizer-file checksums so the rendered
numbers can be traced to their inputs.
The joint-zeroing and thinking tables are transcribed separately from validated
results, with provenance described in their respective sections.
